階段 2 · 交會點

meme.json — 唯一的綁定點

{
  "id": "demo_freeze",          ← 兩條線共用的鍵
  "behavior": "FreezeBehavior",  ← 關卡線決定：做什麼
  "radius": 32,
  "textures": {
    "default": "textures/demo_freeze.png",  ← 美術線提供
    "idle":    "textures/demo_freeze.png"
  }
}
為什麼要這樣拆 美術換一張圖，只要保持 id 不變，所有用到它的關卡都不用改。
