先講清楚關係

它們不是上下游，是同一枚金幣的兩半。
美術線決定金幣長什麼樣（PNG 圖檔）；關卡線決定金幣在哪、做什麼（行為與座標）。
把兩者綁在一起的是一個叫 meme.json 的小檔案 —— 它同時記錄「用哪張圖」和「什麼行為」。

階段 2　交會點兩條線在這裡綁在一起

meme.json — 唯一的綁定點

這個檔案把「一張圖」和「一個行為」配對起來。美術線提供圖，關卡線提供行為，
兩者在這裡合成一個可以被關卡引用的單位。id 是兩邊共用的鍵。 

{
  "id": "demo_freeze",        ← 兩條線共用的鍵
  "behavior": "FreezeBehavior",  ← 關卡線決定：做什麼
  "radius": 32,
  "textures": {
    "default": "textures/demo_freeze.png",  ← 美術線提供：長什麼樣
    "idle":    "textures/demo_freeze.png"
  }
}

關卡裡實際長這樣

關卡檔案不直接引用圖檔路徑，而是透過 memeId 關聯 —— 美術換圖時不必改關卡。

{
  "type": "coin",
  "x": 120, "y": 40,
  "behavior": "FreezeBehavior",
  "memeId": "demo_freeze",          ← 指回 meme.json 的 id
  "skin": {
    "default": "https://cdn.jsdelivr.net/.../demo_freeze.png"
  }
}
